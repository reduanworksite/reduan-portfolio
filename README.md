## About

A minimal, modern, premium portfolio site, built from the earlier Reduan Computer portfolio and expanded into a full multi-page site:

- **Home** (`index.html`) — hero, headline, highlights and social media links
- **About Me** (`about.html`) — who Reduan is and what he believes in
- **My Skills** (`skills.html`) — SEO, Local SEO, Google Business Profile, Meta Ads, Microsoft Office, Organic Growth
- **My Services** (`services.html`) — Local SEO, GBP optimisation, SEO & keyword research, Meta Ads, Office training, marketing education
- **My Projects** (`projects.html`) — Basic Computer Learning, Reduan Typing Master, Reduan Computer, Reduan Digital, TerraNest and this portfolio, each with a working link
- **Contact** (`contact.html`) — email, Facebook pages, location and a Social Media Links section

## Tech

- Pure HTML + CSS + JavaScript — no framework, no build step, fast loading
- Mobile-first, fully responsive, sticky navigation with active-page highlighting
- Premium typography (Inter + Sora), navy / blue / gold palette
- Reveal-on-scroll animations, respects `prefers-reduced-motion`
- Every page is a separate HTML file, so each has its own direct URL and a browser refresh never 404s

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
